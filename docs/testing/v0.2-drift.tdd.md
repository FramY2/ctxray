# CtxRay v0.2 drift guard — TDD evidence

## Source and user journeys

The journeys were derived during the 9 August 2026 implementation run; no
external plan file was used.

1. As a Codex user, I want to compare a saved capability baseline with my
   current setup so I can see added, removed, or changed context sources.
2. As a maintainer, I want a deterministic non-zero exit on drift so CI can
   block an unreviewed capability change.
3. As a privacy-conscious user, I want malformed or ambiguous lockfiles rejected
   before comparison.
