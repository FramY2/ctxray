# v0.3.1 CtxWise executable override — TDD evidence

## Source and user journey

The journey was derived during the v0.3.1 rebrand-completion work:

> As a CtxWise user with a custom Codex executable, I want the current
> `CTXWISE_CODEX_BIN` setting to take precedence while old installations keep
> working, so that the rename is complete without breaking existing setups.
