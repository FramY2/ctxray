# Support

- Use GitHub Discussions for setup questions and usage ideas.
- Use the bug report template for reproducible defects.
- Use private vulnerability reporting for security issues.
- Include `ctxwise doctor`, operating system, Node version, Codex version, and a
  synthetic reproduction. Do not attach private prompt-input or configuration.

If only `ctxwise run`, `quota`, or `doctor` fails on Windows, first verify that
the public `@openai/codex` CLI is installed and callable from a new terminal.
The executable inside the packaged desktop app is not a supported substitute.

The project is community maintained and provides no guaranteed response time.
